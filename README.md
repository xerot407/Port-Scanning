# 🔍 Port Scanning

> A simple tool to scan and identify open or closed ports on a target system using Python and Tkinter.

 💡 Motivation

As a cybersecurity student, understanding how port scanning works is a foundational skill. This project was built to reinforce learning and provide a hands-on tool for basic network analysis.


 🔧 Technologies Used

- Python
- Tkinter
- socket
- threading

 🚀 Key Features

- Scans all **65535 TCP ports**
- Identifies **open** and **closed** ports
- Graphical User Interface built with **Tkinter**
- **Real-time** scanning status updates
- **Multithreaded** scanning for improved performance
